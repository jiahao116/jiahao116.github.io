# Jiahao Cao

Personal academic website: **https://jiahao116.github.io/**

Source code for my academic website, featuring research notes and interests in quantum information and quantum many-body physics.

## Development and deployment

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

To build the static website, run `npm run build`. Pushing to `main` automatically deploys the site to GitHub Pages via [GitHub Actions](.github/workflows/deploy.yml). Site content is maintained in `content/`.
